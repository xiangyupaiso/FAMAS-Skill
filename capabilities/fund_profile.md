# fund_profile — 基金档案（事实层）

> `layer: fact` · 无 persona · 只输出事实与条款原文摘要 · 输出块见 `contracts/famas.contract.json#/blocks/fund_profile`

## 输入

`fund_code`（6 位）· 可选 `as_of`

## 语义字段

`fund_basic` `benchmark` `fee_schedule` `holder_structure` `fund_announcements` `fund_classification`

## 计算与整理口径

| 项目 | 口径 |
|---|---|
| 投资范围 | 股票仓位上下限、可投资产类别、港股通/衍生品/融资融券权限、投资限制条款 |
| 业绩基准 | 主要基准 + 复合基准权重，**照录合同原文**，不判断"匹配度" |
| 费率结构 | 管理费、托管费、销售服务费、申购费（按档）、赎回费（按持有期档）；标注是否含 QDII 附加 |
| 持有人结构 | 机构/个人占比、持有人集中度、最近 2 期机构占比变化；季末快照，标注滞后性 |
| 特殊条款 | 大额赎回条款、清盘触发线、侧袋机制、限购/暂停申购、其他特殊约定 |
| 份额类别 | A/C/E/I 等类别映射、场内 ETF 与场外联接对应关系、各自费率差异 |

## 输出要求

- 结构化输出 `fund_profile` 块；每个字段带 `source`、`as_of`、`confidence`
- 条款类字段保留原文关键句，不做解释性改写
- 无法取得的信息标 `status: "unavailable"`，**不得留空、不得猜测**
- 费率分位属"计算"而非"评价"，可输出数值但不输出"偏高/偏低"等判断词

## 禁止

- 不得输出"基准设置合理""条款对投资者友好"等评价
- 不得对清盘线、限购做概率性预测
- 不得使用非公开或非权威渠道的持有人信息
- 不得夹带任何适配度、评级或时机判断（属 `synthesis`）

# people — 人员画像（事实层）

> `layer: fact` · 无 persona · 只使用公开披露信息 · 输出块见 `contracts/famas.contract.json#/blocks/people`

## 输入

`fund_code` · 可选 `manager_name`

## 语义字段

`manager_roster` `manager_history` `manager_performance` `fund_announcements`

## 计算与整理口径

| 项目 | 口径 |
|---|---|
| 任职经历 | 在任经理、任职起止日、历史管理产品数、共管关系与变更记录、跳槽/离任公告 |
| 能力圈 | 各期重仓行业分布、覆盖行业数、行业偏好稳定性（跨期重合度） |
| 投资风格 | 左/右侧特征、价值/成长倾向、集中/分散、换手率特征；注明判定依据 |
| 稳定性 | 单只基金任职年限、管理规模变化、共管比例、共管团队稳定性；评分须附评分规则 |
| 逆风表现 | 指定熊市/震荡区间内相对同类分位、回撤幅度、超额收益符号；**区间须显式声明** |

## 输出要求

- 结构化输出 `people` 块；每条记录带 `source`、`as_of`、公告日期
- 共管基金须列出全部在任经理，不推定"主理人"
- 任职区间以公告为准，与净值曲线起点不一致时并列标注，不静默对齐
- 数据缺口标 `status: "unavailable"`

## 禁止

- 不得输出"能力圈扎实""管理能力强"等主观评价
- 不得使用非公开个人信息、传闻、社交平台未证实内容
- 不得预测离任概率或未来业绩
- 不得把「基金业绩」直接归因为「经理个人能力」（归因需 `synthesis` 在四段式框架下处理）

# performance_metrics — 业绩与风险（事实层）

> `layer: fact` · 无 persona · 只输出可复算的指标 · 输出块见 `contracts/famas.contract.json#/blocks/performance_metrics`

## 输入

`fund_code` · `lookback`（默认 3y）· 可选 `benchmark_override`（用于基准敏感性检验）

## 语义字段

`fund_nav_history` `index_quotes` `holdings` `benchmark` `turnover_history`

## 计算口径（必须写明方法与窗口）

| 指标 | 口径 |
|---|---|
| 年化收益 | 近 1/3/5 年及成立以来，几何年化；不足窗口标 `insufficient_history` |
| 超额收益 | 相对**合同业绩基准**（复合基准按权重合成），不是相对沪深 300；同时输出 `benchmark_used` |

## 基准版本核对（2026-11-07 首跑新增，跨期对照前必做）

1. 取 `benchmark` 时同时取**生效日 / 版本号 / 基准变更公告**；报告期内若发生变更，必须并列标注新旧基准文本与生效日。
2. **禁止用变更后基准回算变更前区间**，也禁止把不同版本的基准收益率拼成一条连续序列。
3. 跨期（近 1 年 / 3 年 / 5 年）超额与相对排名若跨越基准变更日 → 该区间对照标 `benchmark_version_break`，命中 `judgment/veto-rules.yaml#benchmark_version_change`，结论降为 `weak`。
4. 背景：2026 年《公开募集证券投资基金业绩比较基准指引》过渡期内分批调整，累计超 4000 只存量产品；实测同管理人旗下基金在 2026-06-01、2026-07-27 生效新基准。该事实来自媒体与研报转述，属**非一手来源，需核实原文**，仅用于提示核对义务，不作为数值证据。
| 最大回撤 | 区间内峰值到谷值；附回撤起止日与修复天数，未修复标 `not_recovered` |
| 夏普 / 卡玛 | 夏普 = (年化收益 − 无风险利率)/年化波动；卡玛 = 年化收益/最大回撤；**注明无风险利率取值** |
| 波动率 / 下行风险 | 年化标准差；下行波动按目标半方差计算，注明目标值 |
| 滚动稳定性 | 滚动 12 月收益的分布、正负月份占比、相对基准月度胜率 |
| 风格分析 | 价值/成长、大盘/小盘倾向；季度风格漂移距离需说明是持仓法还是收益回归法 |
| 行业归因 | 前三大重仓行业及占比、HHI、相对基准行业偏离；季报为季末快照 |
| 持仓分析 | 前十大重仓占比、换手率趋势、重仓股留存率 |

## 基准敏感性（供 `research/skill_vs_luck` 复用）

同一基金至少用 2 组基准（合同基准 + 用户指定替代基准）重算超额收益，输出差值。**只报差值，不评判"运气还是能力"**。

## 输出要求

- 结构化输出 `performance_metrics` 块；每个数字带 `source`、`as_of`、`window`、`method`
- 所有计算附「复权方式、频率、窗口、缺失值处理」四项说明
- 季报持仓须标注"季末快照，非实时"

## 禁止

- 不得输出"业绩优秀/糟糕/跑赢大盘值得买"等评价或预测
- 不得用模型记忆填补任何净值、收益率数值
- 不得把估算值写成实测值；估算必须显式标注 `estimated: true`
- 不得给出未来收益推断

# portfolio_view — 组合视角（事实层）

> `layer: fact` · 无 persona · 输出穿透后的结构与风险度量，不给再平衡方案 · 输出块见 `contracts/famas.contract.json#/blocks/portfolio_view`

## 输入

`holdings`（基金代码 + 权重，合计 100%）· 可选 `lookback`

## 语义字段

`holdings` `fund_classification` `fund_nav_history` `index_quotes`

## 计算口径

| 项目 | 口径 |
|---|---|
| 资产配置 | 按各基金**最新披露的股票/债券/现金仓位**加权汇总，不是按基金名称分类；标注报告期 |
| 集中度 | 前三大行业占比、单只基金最大权重、穿透后前十大个股合计权重、HHI |
| 风格偏离 | 价值/成长、大盘/小盘加权暴露；与用户指定基准的偏离度 |
| 相关性 | 基金间净值相关系数矩阵、尾部相关（分位数定义须写明）、危机区间相关性变化 |
| 隐性集中 | 穿透到个股层面的实际重叠；表面分散但底层集中的识别结果，附计算过程 |

## 输出要求

- 结构化输出 `portfolio_view` 块；所有占比带 `weight_basis`（按净资产 / 按持仓市值）
- 权重合计不为 100% 时先报 `weight_sum` 并要求修正，不自动归一化
- 相关系数须写明窗口、频率、复权方式与样本数

## 禁止

- 不得输出"建议减仓 XX""目标配置应为 XX"（属 `synthesis`，且受合规闸约束）
- 不得把相关系数当作因果解释
- 不得用基金名称推断持仓行业
